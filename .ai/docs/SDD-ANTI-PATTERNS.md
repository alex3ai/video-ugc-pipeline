# Anti-Padrões SDD

| Erro Comum | Consequência | Correção |
|------------|--------------|----------|
| Fazer uma fase inteira de uma vez | Perda de foco e inconsistência | Executar apenas uma subtarefa |
| Usar specs ambíguas | IA inventa regras | Tornar critérios concretos |
| Não atualizar docs após mudanças | Drift entre código e specs | Atualizar docs após cada entrega |
| Pular validação | Bugs tardios | Rodar checklist antes de pedir código |
| Ignorar edge cases | Quebras em produção | Exigir edge cases por história |

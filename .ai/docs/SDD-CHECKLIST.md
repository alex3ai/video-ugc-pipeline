# Checklist de Validação

Use sempre antes de pedir código.

- [ ] Todas as entidades do domínio estão nas user stories?
- [ ] Todos os campos obrigatórios estão no schema?
- [ ] Edge cases críticos estão documentados?
- [ ] Regras de negócio têm exemplos concretos?
- [ ] Escopo explícito está atualizado?
- [ ] Versão do documento foi incrementada após mudanças?

> Se faltar um item, pare e corrija as specs antes de pedir código.
